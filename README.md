# Dachshund Enclosure Game

A small mobile puzzle game (Godot 4 / GDScript) inspired by the simplicity of games like enclose.horse, themed around a dachshund whose long body is the core mechanic.

The player extends the dog's body across a grid board by tapping adjacent cells, trying to seal off valuable regions (using the board's border, water, or the dog's own tail as anchor points) before running out of length.
